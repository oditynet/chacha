# chacha
Launcher for android

Лаунчер очень простой: 4 иконки можно выставить на главную панель быстрого доступа. На сам экран выкладывается до 12. Дальше вшит календарь с отображением текущего дня. Приложения и настройки можно скрыть за паролем (но это не security вообще), т.к. настрйоки системные заблокировать нельзя без root. Обои можно выставить из своих фото.
